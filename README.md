# Framerly

Web application for batch framing event photography with automatic centering and manual adjustments.

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
npm install
```

### Development

Start the local Vite development server:

```bash
npm run dev
```

### Verification

```bash
npm test            # Run Vitest unit & integration tests
npm run test:watch  # Run tests in watch mode
npm run typecheck   # Typecheck TypeScript files
```

### Production Build

```bash
npm run build       # Typecheck and bundle with Vite
npm run preview     # Preview production build locally
```
